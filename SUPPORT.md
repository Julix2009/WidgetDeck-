# Support

1. Run `widgetdeck-doctor` and read the WARN / FAIL lines: each one comes with a suggested fix.
2. Check the troubleshooting table in the README (nothing appears, glass looks flat, wrong weather location, ...).
3. Still stuck? Open a GitHub issue with the **bug report** form and paste the full output of `widgetdeck-doctor`.

Only Arch Linux with Hyprland and Quickshell is supported. There is no guaranteed response time; this is a hobby project.
